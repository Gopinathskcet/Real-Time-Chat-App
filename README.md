# Real-Time Chat App

Angular + Node.js + Express + Socket.IO + MongoDB

## Requirements
- Node.js (LTS)
- MongoDB (local Community Edition or an Atlas connection string)
- Cloudinary account (free) for audio/video uploads

## Run the backend
```
cd backend
npm install
copy .env.example .env      (then open .env and fill in the values)
npm start
```

## Run the frontend (in a second terminal)
```
cd frontend
npm install
npm start
```

Open http://localhost:4200
